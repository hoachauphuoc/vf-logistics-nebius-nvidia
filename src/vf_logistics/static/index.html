Trusted Companies (Auto-Clear)

✅ Shipments from these companies are automatically cleared without waiting for AI review, as long as no other red flags are detected (abnormal freight, suspicious destination, etc.). Adding a tax ID enables strict identity matching — if someone claims to be this company but provides a different tax ID, the shipment is blocked immediately.
Example: "Vinamilk" with tax ID "0100107518" → auto-cleared. Someone claiming to be "Vinamilk" with tax ID "9999999999" → identity mismatch → blocked and escalated.

Blocked Companies & Tax IDs (Auto-Reject)

🚫 Shipments from these companies or tax IDs are automatically rejected. Use this for known bad actors, sanctioned entities, or shell companies you've identified.
Example: Add "Shadow Logistics LLC" → any shipment from this company is instantly rejected, no AI review needed.

Safe Domestic Routes

🚚 Low-value shipments on these routes are automatically cleared. This is designed for high-volume domestic freight that rarely poses a risk.
Example: "Ho Chi Minh City → Hanoi" with value under $100 → auto-cleared.

Low-Value Threshold

Shipments below this value on safe routes above are auto-cleared. Default: $100 USD.

When Can the AI Release Shipments?

🤖 These settings control when the AI agent can approve and release a shipment on its own, without waiting for a human reviewer. If any condition below is not met, the shipment goes to the Review Queue for a human to decide.
Example: If max value is $25,000 and max risk is 39, a $10,000 shipment with risk score 25 → AI can release. A $50,000 shipment → must wait for human review.

Restricted Goods (Always Require Human Review)

⚠️ Shipments containing these HS codes (product categories) always require human review, regardless of risk score. Use this for dual-use goods, controlled substances, or sensitive materials.
Example: HS code "8401" (nuclear reactors) → any shipment with this code goes to human review.

Restricted Destinations

Shipments to these countries always require human review, regardless of other factors.

Mandatory Human Review Triggers

These conditions always send the case to a human reviewer, regardless of risk score or AI analysis.

Suspicious Activity Reports (SAR)

Control whether the AI agent can draft or submit formal Suspicious Activity Reports to regulators.
