Delegation Boundary

The agent does not earn authority by reasoning well. A human publishes a machine-readable boundary and the agent operates inside it. With no active boundary the system is SUSPENDED: it still analyses and proposes, but the execution gate refuses every protected action.

Publish a boundary

Publishing supersedes the previous version. Every executed action records the version that permitted it, so a past decision can be reconstructed against the policy in force at the time.
